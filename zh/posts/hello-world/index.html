你好，世界：博客上线了

这个博客基于 Astro 构建，支持中文、英文、日文三种语言，可切换主题，并可静态部署到 GitHub Pages 与 Cloudflare Pages。

2026年10月20日约 1 分钟
  • 公告
  • Astro

本文其他语言版本： English · 日本語

欢迎来到这里。这是博客的第一篇文章，简单介绍一下它能做什么。

主要特性

  • 多语言：中文、英文、日文，每篇文章可以有任意语言的译文，页面会自动关联。
  • 主题切换：浅色 / 深色 / 跟随系统，外加五套配色，选择会被记住。
  • 全文搜索：构建时生成静态索引，中日文同样可用，不需要服务器。
  • SEO 完备：hreflang、站点地图、RSS、Open Graph、结构化数据。
  • 纯静态：可以部署到任何静态托管服务。

写作方式

在 src/content/blog/<语言>/ 下新建 Markdown 文件即可，文件名就是 URL：

npm run new -- my-first-post

同一个文件名放在不同语言目录下，即被视为互为译文。

好的工具应该让你忘记它的存在，专注于写作本身。
