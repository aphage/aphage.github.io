こんにちは、世界：ブログを公開しました

Astro で構築し、中国語・英語・日本語に対応。テーマ切り替えが可能で、GitHub Pages と Cloudflare Pages に静的デプロイできます。

ようこそ。最初の記事として、このブログでできることを簡単に紹介します。

主な機能

  • 多言語対応：中国語・英語・日本語。各記事の翻訳は自動的に関連付けられます。
  • テーマ切り替え：ライト / ダーク / システム連動、さらに 5 種類のカラー。選択は保存されます。
  • 全文検索：ビルド時に静的インデックスを生成。日本語・中国語にも対応し、サーバー不要です。
  • SEO 対応：hreflang、サイトマップ、RSS、Open Graph、構造化データ。
  • 完全静的：どの静的ホスティングにもデプロイできます。

書き方

src/content/blog/<言語>/ に Markdown ファイルを作成するだけです。ファイル名がそのまま URL になります：

npm run new -- my-first-post

異なる言語フォルダに同じファイル名を置くと、互いの翻訳として扱われます。

良い道具は存在を忘れさせ、書くことそのものに集中させてくれる。
